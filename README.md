# Raksha360 Download Portal

Official mobile-first web portal for downloading and verifying the **Raksha360** Android Civic Safety Application.

- **Production APK Release Asset:** `Raksha360-v1.0-release.apk`
- **Application ID:** `com.aistudio.naarikavach.safe7x`
- **Release Version:** `1.0 (Build 1)`
- **SHA-256 Checksum:** `bd2b74d3beeb62873952010102240a5efca91eb61485d04aca06c75348e29865`

## Hosted on Vercel
This website is built with zero-dependency static HTML/CSS/JS and deployed on Vercel.

### Continuous Deployment & Updates
- Commits pushed to `main` automatically redeploy the landing page on Vercel.
- The **Download APK** button points to the GitHub Releases latest download redirect:
  `https://github.com/ombangare/Raksha360-Download-Website/releases/latest/download/Raksha360-v1.0-release.apk`
- When a new APK is published as a GitHub Release asset with the name `Raksha360-v1.0-release.apk` (or updated release asset), the download link automatically resolves to the latest release asset without requiring changes to the website code.
