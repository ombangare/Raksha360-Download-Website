Important Operational Disclosures & Controlled Testing Notice

Raksha360 v1.0 is published as a controlled-testing build for designated pilot evaluations and community safety validation. Please review these operational boundaries before installation:

  • Official 112 Dispatch Gateway: Internal coordination tool. Direct public 112 gateway integration is not configured. In an immediate life-threatening emergency, always dial 112 directly.
  • Voice SOS Model Provisioning: Vosk offline speech recognition models (~55 MB) are not pre-bundled into this starter APK. Voice SOS requires running scripts/prepare-voice-model.ps1 from the repository.
  • Phone-Shake Trigger: Phone-shake emergency trigger is not implemented in v1.0. Do not rely on shaking the phone to trigger an alert.
  • Device Authentication: Pre-shared device token architecture is intended for controlled pilot devices. Dynamic individual device enrollment is currently in development.
Audited Architecture

Verified Safety Capabilities

Every listed feature is backed by active, test-verified Kotlin source code in the repository.

One-Touch Emergency SOS

Immediate panic activation via the Home Screen button. Spawns an ongoing foreground emergency service, vibrates device for confirmation, and automatically captures audio evidence.

Verified & Operational

Offline-First Resilience

When disconnected from mobile data or Wi-Fi, emergency events and location breadcrumbs are AES-encrypted and queued in local Room database storage until connectivity restores.

Verified & Operational

Honest Location Protocol

Acquires precise GPS/network coordinates. If location permissions are denied or GPS is disabled, the app defaults transparently to Sadar seed coordinates flagged as fallback.

Verified & Operational

Child & Family Geofencing

Define safe perimeter zones around schools and residences using Android GeofencingClient. Zero cloud data storage guarantees absolute family privacy and prevents cross-user leaks.

Local-Only · Privacy Protected

Offline Voice SOS

Embedded Vosk speech recognition pipeline supporting wake phrases and enrolled-speaker cosine similarity checks. Requires local model provisioning prior to first activation.

Requires Model Asset Setup

Phone-Shake Trigger

Physical shake activation using accelerometer sensor listeners is currently absent from the active codebase. To prevent false confidence, it is explicitly excluded from active triggers.

Not Implemented in v1.0

Getting Started

How to Install on Android

Follow these 4 simple steps to safely install the APK on your physical Android device.

1

Download APK

Tap the Download APK button above to download Raksha360-v1.0-release.apk directly from the official release asset server.

2

Enable Unknown Apps

If prompted by Android, go to Settings → Apps → Special app access → Install unknown apps and allow permission for your browser or File Manager.

3

Install & Launch

Tap the downloaded file in your Notification shade or Downloads folder, tap Install, and open Raksha360.

4

Grant Permissions

Grant Location (select Precise/While in use) and Notifications to allow real-time emergency alert dispatch.
